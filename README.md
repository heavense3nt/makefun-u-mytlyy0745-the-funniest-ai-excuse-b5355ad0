One line: the funniest excuse an AI agent gives after failing a task.

`main.ts` writes the excuse to `/output/entry.txt` (or `MAKEFUN_OUTPUT_DIR` when set), 1–200 characters, UTF-8.

## Run

```sh
node main.ts
```
